
# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python program
that combines different useful tools in one
menu-driven application.

## Tools Included

1. Simple Calculator - Performs addition,
   subtraction, multiplication and division.
2. To-Do List Manager - Allows users to add,
   view and remove tasks.
3. Number Guessing Game - Allows users to
   guess a secret number between 1 and 10.
4. Grade Checker - Checks marks and displays
   the corresponding grade.

## Technologies Used

- Git and GitHub

## Python Concepts Practiced

- Variables
- User input and output
- Conditional statements
- While and for loops
- Lists
- F-strings
- Comments
- Functions

## How to Run the Project

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   python toolkit.py

6. Select a tool from the displayed menu.
